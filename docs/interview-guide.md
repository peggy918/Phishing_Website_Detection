# 使用者訪談大綱（G1 問題證據）

> 目的：確認「收到可疑網址時不知道怎麼判斷」是真實存在的問題，而不是本人的假設。對應報告 p.4–p.5（G1）。
> 對象：1–2 人，最好不是資訊相關科系，例如家人、長輩、非本科系同學、打工同事。
> 時間：約 10 分鐘，可面談、通話或視訊。

## 開始前（約 1 分鐘）

照著唸，取得口頭同意：

> 「我在做一個檢查可疑網址的專題，想請你聊聊收到可疑連結的經驗，大約 10 分鐘。報告裡不會寫你的名字，只會寫像『受訪者 A，50 多歲』這樣的代號。不需要給我看你真的收到的簡訊或對話，用說的就好。哪一題不想回答都可以跳過。可以嗎？」

- 不錄音也可以，邊聽邊記重點即可。如果要錄音，要先另外問對方同不同意。
- 不要記對方的電話、帳號，或簡訊裡的網址原文。

## 一、經驗（約 3 分鐘）

1. 最近半年，你有沒有收過覺得怪怪的連結？是從哪裡收到的？（簡訊、LINE、臉書、Email……）
2. 可以說說印象最深的一次嗎？內容大概在講什麼？
3. 那次你最後怎麼處理？（有點開、沒點、刪掉、問別人……）
4. 你身邊有沒有人因為點了連結被騙，或差點被騙？

## 二、現在怎麼判斷（約 3 分鐘）

5. 收到連結時，你通常怎麼判斷能不能點？看哪些地方？
6. 你有沒有遇過「真的分不出來」的時候？那時候你怎麼做？
7. 你知道 165 反詐騙專線，或其他查詢管道嗎？用過嗎？用起來覺得怎麼樣？
8. 如果要你自己查一個網址，最麻煩的地方是什麼？

## 三、需要什麼（約 3 分鐘）

9. 如果有一個工具，貼上網址就幫你檢查，你會想用嗎？什麼情況下會用、什麼情況不會？
10. 檢查完，你最想知道什麼？（例如：危不危險、為什麼、接下來該怎麼做）
11. 如果結果說「未發現明顯風險跡象」，你會怎麼理解？會因此放心點開嗎？
12. 有什麼原因會讓你不信任這種工具？

## 結束（約 30 秒）

> 「謝謝你，這些對我很有幫助。之後如果有網站可以試用，可以再請你幫忙看看嗎？」

最後一句是為複審的使用者測試先約人，對方說不要也沒關係。

## 訪談時注意

- **不要先介紹本系統**，也不要給看畫面，免得對方順著你的想法回答。第 9 題才提到工具，而且只問想不想用。
- 不要問引導式問題。例如不要問「你是不是常常分不出詐騙連結？」，要問「你怎麼判斷？」。
- 對方答得很短時，可以追問「可以多說一點嗎？」或「那時候為什麼這樣做？」。
- 對方答出和你預期不同的內容，也要照實記下來。這也是證據，例如「他說從來不點連結，所以覺得不需要工具」。

## 紀錄表（每位受訪者一份）

| 項目 | 內容 |
|---|---|
| 代號 | 受訪者 A |
| 年齡層 | 例：50–59 歲 |
| 職業類別 | 例：服務業（不寫公司名） |
| 日期與方式 | 例：2026-11-08，面談 |
| 時長 | 例：12 分鐘 |

| 題號 | 重點（盡量記原話） | 對應報告 |
|---|---|---|
| 1–4 | | p.4 問題是否存在 |
| 5–8 | | p.4–p.5 現有做法的不足 |
| 9–12 | | p.5 需求、p.6 系統要做什麼 |

訪談後請補一段：**這次訪談有什麼和我原本想的不一樣？** 這段最能證明你真的有參考使用者的說法。

## 寫進報告時

- 寫清楚只訪談 1–2 人、怎麼找到受訪者、時間多長，不能說成代表一般大眾。
- 和 165 話術、政府通報資料一起寫：資料說明問題規模，訪談說明一般人實際遇到的狀況。
- 引述用代號，例如「受訪者 A（50 多歲）：『……』」。
